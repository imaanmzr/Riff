# Agentic Workflow

For planning, read planning/WORKFLOW.md. For explicit implementation/execution,
read execution/WORKFLOW.md as well. Planning completion alone does not authorize
execution. Respect target project instructions and preserve existing user work.
For changes to this workflow, run both planning and execution regression tests.
For checkpoint/handoff/resume, also follow recovery/WORKFLOW.md. Run recovery
regression tests when changing workflow state or readiness rules.
For agent assignment/model selection, read routing/WORKFLOW.md. Run routing
regression tests when changing dispatch, budgets, or capabilities.
