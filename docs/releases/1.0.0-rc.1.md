# Riff 1.0.0-rc.1

This is a prerelease for evaluation before stable 1.0.0. Riff keeps planning,
execution, reviews and recovery in local Markdown/JSON records across agent
sessions. It runs locally with Python 3.10 or newer and no runtime dependencies.

## Changes since 0.8.0

- Planning asks a few focused questions when material intent or important edge
  cases are missing, then continues when those gaps are resolved.
- `riff status` shows evaluated readiness, task progress, current and historical
  reviews, dependency waits and the next action/continuation command. Use
  `riff status TASK --details` for task and review history.
- New project settings use `.riff/`. Legacy-only `.engineering-workflow/`
  settings remain readable and writable; duplicate settings directories are
  rejected rather than merged.
- `riff doctor` identifies conflicting skill copies, complete prerelease
  versions, integrity problems and LF/CRLF-only text changes. Updates preserve
  substantive edits and select Cursor/shared installations explicitly.
- Legacy migration offers concrete next steps and optional source-manifest
  binding. Migration remains explicit, creates a backup and returns the plan
  to DRAFT for review; execution/recovery records are not silently rewritten.
- Packages carry MIT notices, pinned offline rendering assets, and clearer
  installation, contributor and release guidance. CI qualifies regression suites
  and fresh package installations.

## Install or upgrade

Follow the [installation guide](https://github.com/imaanmzr/Riff/blob/v1.0.0-rc.1/docs/installation.md) for Windows, Linux/macOS,
standalone CLI and pipx commands. Select tag `v1.0.0-rc.1` for this candidate.
The Python archives are versioned `1.0.0rc1`; `riff --version` reports
`Riff 1.0.0-rc.1`. Downloadable packages have a `SHA256SUMS` companion file.

Update the CLI first, then each project's skill using `riff update --host HOST`.
Run `riff doctor --host HOST` and inspect `riff status` afterward. Preserve
local skill edits before updating. Keep legacy settings in place or manually
rename them while Riff work is stopped; reviewed source paths then need the
usual freshness review. See the [upgrade guide](https://github.com/imaanmzr/Riff/blob/v1.0.0-rc.1/docs/installation.md#upgrade-to-100-rc1).

## Compatibility and known limits

The CLI installs project skills for Codex, Cursor, VS Code GitHub Copilot and
Claude Code. Automated coverage verifies those installation/update paths, not
live behavior in each host. Development evidence includes Codex and reported
Cursor use; live VS Code Copilot and Claude Code sessions remain unqualified.
CI targets Windows and Linux with Python 3.10 and 3.13. macOS installation is
documented but has no dedicated CI runner in this candidate.

Workflow commands print prompts for the user to send to an agent. Riff does not
call provider APIs, run a background scheduler or automatically retry tasks.
The host supplies models and subagents. Routing budgets are planning estimates,
not billing controls; token/cost savings and quality improvements are unmeasured.
Validators check structure, freshness and recorded bindings; the coordinator
must assess the actual implementation and independence of reviews.

Please [report RC issues](https://github.com/imaanmzr/Riff/issues/new/choose) with
your OS, Python, host, Riff version and a minimal reproduction. Remove private
source and credentials from shared records.
